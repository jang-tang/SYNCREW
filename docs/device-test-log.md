# 실기기 시험 기록

실기기(휴대폰)에서 한 시험을 여기에 남긴다. 시나리오 ID·절차는 `docs/HANDOFF.md` 5절.
에뮬레이터·시뮬레이터·웹 결과는 여기에 적지 않는다 (실기기 검증이 아님).

**요약 (2026-10-18)**: T2(10-14–15, Galaxy S22·iPhone 17 Pro) 문장 단위 통화 양쪽 통과·Android 헤드셋 마이크 실패 / S3 iOS(10-17 밤, iPhone 15 Pro Max) 점검 화면·F 스트리밍 통화 통과, voice processing 무한 재시작 수정(커밋 `4fd2d9d`) / 남은 것: iOS 통화 시작 때 에코 제거 꺼짐, iOS G·H(실제 OpenAI), Android S3 전부, S4.

**2026-10-17 인수인계 후 (새 담당자 현슈 Mac): Android 실기기 없음 → Android 시험은 진행하지 않음.** 아래 표의 Galaxy S22·iPhone 17 Pro 는 T2 때(팀장 PC) 쓴 기기다. 새 담당자가 가진 기기는 iPhone 15 Pro Max(iPhone16,2) + AirPods Pro 뿐이라, S3 실기기 시험은 **iOS 만** 할 수 있다 (상대 역할은 `server/scripts/call-peer.ts`). 그래서 다음은 Android 기기를 구할 때까지 미검증으로 남는다: Android 헤드셋 마이크 무음(10-14 C 실패) 재시험, Android 스트리밍 통화(F·G·H), Android ↔ iPhone 2대 통화(S4).
